# 📊 داشبورد بخش‌بندی مشتریان (Customer Segmentation Dashboard)

این داشبورد به منظور تحلیل رفتار خرید مشتریان و دسته‌بندی آن‌ها بر اساس معیارهای ارزش و وفاداری طراحی شده است.

### 🔑 شاخص‌های کلیدی (KPIs)
*   **فروش کل:** ۲,۳۲۶,۵۳۴
*   **تعداد مشتریان:** ۸۰۴
*   **میانگین ارزش مشتری:** ۲,۸۹۴
*   **میانگین تکرار خرید:** ۶.۳۵۷

### 📈 بخش‌های اصلی داشبورد
1.  **نمودار پراکندگی (Scatter Plot):** نمایش توزیع مشتریان بر اساس "ارزش مشتری" (محور افقی) و "فاصله از آخرین خرید" (محور عمودی) به همراه خط میانه (Median).
2.  **نمودار درصد فروش:** نمایش سهم فروش به تفکیک گروه‌های مشتریان:
    *   ارزشمند (بیشترین سهم: ۵۵.۸۶٪)
    *   وفادار (۲۸.۷۵٪)
    *   معمولی (۱۲.۱۲٪)
    *   کم‌ارزش (۳.۲۸٪)
3.  **نمودار تکرار خرید:** مقایسه بصری حجم/تکرار خرید در چهار گروه مشتریان.

### 💡 نتیجه‌گیری کلیدی (Insight)
مشتریان **ارزشمند** با وجود اینکه تنها **۲.۹ برابر** مشتریان کم‌ارزش هستند، اما سهم خرید آن‌ها **۱۷ برابر** بیشتر است. بنابراین، این بخش از مشتریان باید **اولویت اول** تخصیص منابع بازاریابی باشند.
